## Entry: 2026-10-26 — winget 설치 직후 uv·ffmpeg가 현재 셸 PATH에 없음
- **상황**: 신규 Windows 11 환경, `winget install astral-sh.uv` / `Gyan.FFmpeg` 직후 같은 Claude Code 셸에서 `uv --version` 실행
- **증상**: `bash: uv: command not found`, `which: no ffmpeg in (...)`
- **원인**: winget은 사용자 PATH 레지스트리만 갱신함. 이미 떠 있는 프로세스(터미널·Claude Code)는 이전 PATH를 상속함
- **해결**: 새 터미널을 열거나, 현재 셸에서 `export PATH="$LOCALAPPDATA/Microsoft/WinGet/Packages/astral-sh.uv_.../:$LOCALAPPDATA/Microsoft/WinGet/Packages/Gyan.FFmpeg_.../ffmpeg-*/bin:$PATH"`
- **검증**: `uv --version` → `uv 0.13.5`, `ffmpeg -version` → `9.0.2-full_build`

## Entry: 2026-10-26 — Scribe 약어 음역이 표시 정렬 임계값에 걸려 원문 복원 실패
- **상황**: `numeric_display.align_display_words` 단위 테스트, 대본 `S&P 500` ↔ Scribe `에센피 오백`
- **증상**: 표시 단어가 `S&P`가 아니라 `에센피`로 남음
- **원인**: 발음 key `에스앤피` vs `에센피` 유사도 0.57 < 임계값 0.6
- **해결**: `SPAN_MATCH_THRESHOLD = 0.5` (equal 블록 사이 replace 구간이라 위치 근거가 강함)
- **검증**: `uv run pytest tests/test_planners.py -q` 통과

## Entry: 2026-10-26 — 표시 정렬로 합쳐진 지수명 단어에서 NumberCard 누락
- **상황**: `samples/storyboard.md` 실제 실행(job `sf_20261026_5fbed5`), Daniel voice

- **해결**: `_index_label`에서 공백 포함 지수명으로 시작하는 단일 단어도 인식 (`md2short/data_extract.py`)
- **검증**: `tests/test_planners.py::test_card_label_uses_sentence_subject_and_merged_index` 통과
